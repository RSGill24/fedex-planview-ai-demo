# Demo 1 Script — Planview Logbook Modeling Agent

## Objective
Show how agentic AI can help a data architect analyze a Planview-like Logbook source and produce BigQuery modeling artifacts, quality rules, and architecture review notes.

## Talk track
1. This is synthetic data, not the FedEx operating model.
2. The purpose is to demonstrate an architecture capability on GCP.
3. The architect remains in control; AI generates recommendations, not production changes.
4. The output can become the starting point for governed data product design.

## Live demo flow
1. Open the Streamlit app.
2. Show the raw Logbook JSON sample.
3. Run the modeling workflow.
4. Review Source Analysis.
5. Review Silver/Gold model recommendation.
6. Review quality rules.
7. Review architecture risks and recommendations.
8. Close by explaining how Demo 2 turns this into a multi-agent Data Product Factory.

## Key message
AI is useful when grounded in metadata, constrained by architecture standards, and used to produce artifacts that humans review.
